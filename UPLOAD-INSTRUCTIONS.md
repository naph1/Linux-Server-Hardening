# GitHub Upload Instructions

1. Download and extract `Linux-Server-Hardening-Upload.zip`.
2. Open the extracted `Linux-Server-Hardening-Upload` folder.
3. Create a new public repository on GitHub named `Linux-Server-Hardening` (or another name you prefer).
4. Upload the **contents** of the extracted folder, not the ZIP file itself and not an extra nested parent folder.
5. Confirm that `README.md` appears on the repository front page.
6. Open the README links and check the three portfolio screenshot links.
7. Add the repository URL to the Linux hardening case file on your portfolio when ready.

## Before publishing

- Review every statement for accuracy.
- Check the screenshot links remain accessible.
- Do not upload VM disks, private keys, passwords, tokens, or unredacted logs.
- Do not claim that the new verification helper was used during the original lab.
- No license has been selected or added. Choose one only if you want to define reuse permissions for the repository.
